# 艺术字矢量化验收标准

唯一需求基线为项目 `docs/艺术字图片转矢量图-需求.docx`。本文件按该需求组织验收，阈值与测试范围保持原要求。

## 必须满足的结果

| 项目 | 标准 | 验证方法与证据 |
| --- | --- | --- |
| 输入资格 | PNG/JPG/WEBP，至少 500×500，单文件不超过 5MB，主体占画面至少 60% | 保留原文件、尺寸、字节数、主体标注与占比定义；按原图计算 |
| 轮廓 | 吻合度至少 90%，平滑，无明显锯齿、变形、断笔、粘连、毛刺 | 独立对齐参考、原始与容差分分别记录，并检查局部放大图 |
| 特征 | 衬线、连笔、飞白、笔触纹理、尖角和圆角等保留至少 85% | 独立标注适用特征与对应区域；综合代理分用于诊断 |
| 节点 | 每个字 50～500 个锚点，路径平滑，控制点无冗余 | 固定 SVG 锚点计数方法，记录真实字数和逐字结果；多字平均值另列 |
| 颜色 | 适用单色与标准案例色差不超过 3%，颜色位置和面积保持 | 原始像素参考、RGB/HEX 色值核对、合成回渲图 |
| 渐变 | 至少 8 级，过渡自然，无明显断层和色斑 | 独立素材标签确定适用性，检查色标和回渲效果 |
| 单张速度 | 输入不超过 1000×1000，完整转换不超过 5 秒 | 固定硬件和请求选项，记录完整服务调用与前端等待；缓存耗时单列 |
| 批量 | 100 张不同风格的合规素材，在 10 分钟内完成 | 实际批量入口、统一参数、实测时钟、ZIP 解压及原图映射 |
| 重复一致性 | 相同参数转换 10 次，输出偏差不超过 5% | 同时检查路径、颜色和结构；完全一致的 SVG 哈希可证明对应内容一致 |
| 输出与编辑 | SVG 透明背景、正确 xmlns/viewBox、命名分组和可编辑路径；按要求提供 AI/EPS/PDF | XML 结构检查、独立渲染、实际编辑软件验证 |
| 浏览器 | Chrome、Firefox、Edge、Safari 渲染一致 | 固定版本，记录同输入同文件截图与差异 |
| Illustrator | Illustrator 2020+ 正常打开并编辑 AI，无错误和路径错乱 | 记录软件版本、打开及选中改色/编辑结果 |
| 首次使用 | 非技术人员 3 分钟内完成首次转换 | 保留操作步骤和实际计时 |
| 部署与交付 | 本地或私有部署，提供样本、对比图、矢量文件及使用、调参和部署文档 | 冻结版本、文件哈希、可复现命令及证据索引 |

主体占比当前程序用前景外接矩形估计，正式验收仍须明确原文占比定义并独立核定。自动裁切会记录来源变换，输入资格依据裁切前原图。

## 判定状态

每项使用 `pass`、`fail`、`untested`、`not_applicable`。任一失败则该项集合失败；有待测项则保留待测。缺少独立参考、真实字数、适用性标签或软件环境时，记录证据缺口。

`metrics.checks` 属于内部诊断；`metrics.assessment` 按单张需求记录检查状态。正式交付还需要批量、软件兼容、视觉和首次使用证据。程序内部多色主色匹配、整体内孔数量和加权特征分均为辅助测量，分别保留计算口径。

局部拓扑检查比较前景区域和孔洞的位置、分裂、合并与形变。默认参数为最小区域 4 像素、对应区域 IoU 至少 85%，前景 8 连通、背景 4 连通。这些参数用于定位局部损失，正式特征验收还需标注与目检。

## 样本与参考

`samples/images` 的 25 组合成输入用于诊断和回归。现有样本原图主体占比不足 60%，不能计入合规业务素材通过率。生成器真值使用背景色差阈值或显式 alpha/字形，必须记录边缘定义和几何对齐。

真实业务验收应冻结合规原图、来源信息、真实字数、适用特征、渐变标签和独立参考。保持困难样本在测试集合中，失败结果逐项保留。正式百张测试必须使用 100 张不同输入；重复图片的性能诊断单独列出。

## 执行与产物

```bash
python -m pytest tests -q
node --check app/static/app.js
node tests/frontend_workflow.mjs
python eval/regression_req.py -o out/regression --preset all --repeat 10 --repeat-samples 25
```

回归脚本退出码为 0 表示脚本范围内通过、1 表示存在失败、2 表示仍有待测。单张与重复转换结果共同影响退出码。报告明确列出待补的项目级检查。

对每个最终版本保留源码哈希、使用参数、SVG 与独立渲染图、机器可读报告和失败标注。候选版验证说明见 `候选版验证说明.md`，已知失败保留在对应报告中。
